# Nostr Voting (Streamlit)

Voting application on the Nostr protocol with a Streamlit interface.

## Features

- Nostr client
- Admin and user views
- SQLite storage

## Tech Stack

- Python

## Getting Started

```bash
git clone https://github.com/ghostland-dev/vote-nostr-app-streamlit.git
cd vote-nostr-app-streamlit
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
